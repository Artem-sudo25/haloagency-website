# Blog Publishing Checklist

Date: 2026-03-23
Goal: Turn draft articles into publishable blog pages without extra strategy work.

## Shared Rules

- Keep one CTA only at the end of each article.
- Add one practical visual per article.
- Add one real case-study link inside the body, not only at the end.
- Keep intro tight. No long warm-up before the answer.
- Make the “Короткий ответ” block visually distinct in layout.
- Add article schema once the `/blog` route is implemented.
