# /lp/v2 Free Audit Landing Page Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a high-conversion, warm-aesthetic landing page at `/lp/v2` for a free 20-min diagnostic call, A/B-testable against `/lp/experimental`.

**Architecture:** Two files — `app/lp/v2/page.tsx` (metadata) and `app/lp/v2/LPV2Client.tsx` (full client component). LayoutShell already suppresses site nav/footer for all `/lp/*` routes. Body carries `bg-ha-bg text-white` globally — the page's `<main>` overrides both with explicit background and text colors.

**Tech Stack:** Next.js 15 App Router, Tailwind CSS v4 (arbitrary values), `next/font/google` (Plus Jakarta Sans), Lucide React, native fetch to `/api/webhook/lead`.

    websiteOrProfile: "",
    monthlyBudget: "",

    consent: false,
  });

    return Object.keys(e).length === 0;

          type: "growth-audit-v2",
          lead_id: crypto.randomUUID(),
          source: "lp_v2",
          landing_page_type: "v2",

          email: values.email.trim(),
          websiteOrProfile: values.websiteOrProfile.trim(),
          monthlyBudget: values.monthlyBudget.trim(),
          service: "Free Growth Audit",
          value: 0,
          currency: "CZK",
          consent_given: true,
          timestamp: new Date().toISOString(),

        const d = await res.json().catch(() => ({ error: "Ошибка отправки" }));
        throw new Error(d.error || "Ошибка отправки");

      setValues({ name: "", websiteOrProfile: "", monthlyBudget: "", email: "", consent: false });
